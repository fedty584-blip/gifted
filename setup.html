ตั้งค่าบัญชีแอดมิน (ทำครั้งเดียว)

หน้านี้ทำงานในเบราว์เซอร์ของคุณเท่านั้น ไม่ส่ง token หรือรหัสผ่านไปที่ใด

ผู้ใช้และรหัสผ่าน

ได้แล้ว! ทำต่ออีก 3 ขั้นตอน

1) กด "คัดลอก"   2) เปิด repo ใน GitHub → เข้าโฟลเดอร์ data → Add file → Create new file → ตั้งชื่อ auth.json   3) วางข้อความ แล้วกด Commit changes (รอ 1–2 นาที แล้วล็อกอินได้เลย)

รหัสผ่านสั้นกว่า 8 ตัว คนที่โหลดไฟล์ auth.json ไปอาจเดารหัสได้ แนะนำให้ใช้ 8 ตัวขึ้นไป
